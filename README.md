# Guía Coronda — GitHub Pages

## Subida rápida
Subí TODO el contenido de esta carpeta al repositorio:
- index.html
- privacidad.html
- robots.txt
- carpeta assets/ completa

`index.html` tiene que quedar en la raíz del repositorio publicado.

## Imágenes
Todas las imágenes de esta versión están dentro de `assets/` y son SVG locales. El sitio no depende de hotlinking de imágenes externas.

## GitHub Pages
Repository > Settings > Pages > Build and deployment > Source: Deploy from a branch > Branch: main > Folder: / (root) > Save.

GitHub Pages busca `index.html` en el nivel superior de la fuente publicada.

## Importante
Las ilustraciones locales evitan imágenes rotas, pero no reemplazan fotografías reales. Para una versión fotográfica, agregá fotos propias o con licencia clara dentro de `assets/` y cambiá las rutas correspondientes.

## Monetización
Antes de AdSense: publicar contenido original, política de privacidad/cookies adecuada, navegación clara y cumplir las políticas de Google. El botón de Cafecito está preparado pero necesita tu enlace real.
